## Version Information

All project were analyzed / scanned with the [OSS Review Toolkit] (ORT), an Open Source suite of tools to automate software compliance checks.
The latest [release 43.0.0] of ORT was used as part of an [ORT Server] instance hosted at [Double Open].

## Type of SBOM

The [ORT analyzer] performs Software Composition Analysis (SCA) on the source code of software projects.
As such the Software Bill-of-Materials (SBOMs) generated by the [ORT reporter] are so-called "Source SBOMs".

## SBOM Validation

The [ORT reporter] as built-in automated validation of the SBOMs against their respective schema definitions.

## Additional Information

Generated SBOMs were not enriched or manually edited in any way but taken as-is from the automated compliance pipeline implemented by the [ORT Server] instance.
The only human-curated information that was automatically taken into account are so-called "package curations" to fixup broken metadata in Open Source software packages.
These curations are maintained by the ORT community and publicly available [inside of the ORT config repository].
